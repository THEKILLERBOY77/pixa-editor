# Pixa — личный фоторедактор (PWA для iPhone)

Работает в Safari и ставится на экран «Домой» как приложение. Фото никуда не отправляются: вся обработка идёт на телефоне.

## Как поставить на iPhone

PWA нужно раздавать с какого-то адреса. Два способа:

### Вариант A. Бесплатный хостинг с HTTPS (рекомендую)
Нужен для полноценной установки и офлайн-режима. Подойдёт любой статический хостинг:
- Netlify Drop (netlify.com/drop): перетащите папку с проектом, получите ссылку.
- Cloudflare Pages или GitHub Pages.

Дальше на iPhone: откройте ссылку в **Safari** → «Поделиться» → «На экран “Домой”».

### Вариант B. Временно с компьютера по Wi-Fi
В папке проекта выполните:

```powershell
python -m http.server 8080
```

Узнайте IP компьютера командой `ipconfig` (строка IPv4) и откройте на iPhone `http://<IP>:8080` в Safari. Телефон и компьютер должны быть в одной сети. Это работает как сайт, но без офлайна: Service Worker требует HTTPS.

## Что умеет

- **Обрезка:** свободная и по пропорциям, поворот на 90°, зеркало, выпрямление.
- **Фильтры:** 15 пресетов с регулировкой интенсивности.
- **Настройка:** экспозиция, яркость, контраст, насыщенность, живость, тепло, оттенок, света, тени, выцветание, резкость, виньетка, зерно и «Авто».
- **Ретушь лица:** гладкая кожа, осветление, овал лица, размер и блеск глаз, белые зубы, помада (6 оттенков).
- **AI:** автоулучшение, удаление, замена и размытие фона (люди), ластик объектов, увеличение ×2.
- **Эффекты:** эскиз, мультик, пиксели, глитч, дуотон, свечение, размытие.
- **Текст, стикеры, рисунок, рамки, коллажи (2–9 фото).**
- Отмена и возврат, сравнение с оригиналом (кнопка с глазом, удерживать), сохранение в JPG или PNG.

## Важно знать

- При первом запуске ретуши и «Фона» нужен интернет: скачиваются модели MediaPipe (около 10 МБ для лица и 1 МБ для фона). После этого они кэшируются, если приложение открыто по HTTPS.
- Удаление фона распознаёт **людей**. Предметы и животных эта модель не вырезает.
- «Ластик» и «Качество ×2» классические алгоритмы, а не генеративный AI. Хорошо для небольших объектов и ровного фона, а большие области получаются размытыми.
- Рабочий размер фото ограничен 3072 px по длинной стороне, чтобы не упереться в память iPhone.
- Нет генерации картинок с нуля (AI-арт): для неё нужен внешний сервис.
